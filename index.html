1. 脚本功能教学
远程引用 (Loadstring) 使用此代码从 GitHub 自动同步最新版 zhiUI。 
local zhiUI = loadstring(game:HttpGet("https://raw.githubusercontent.com/yda66722-hash/zhiUI/refs/heads/main/zhiUI"))()
AddToggle (开关功能) 用于控制持续运行的逻辑（如自动攻击）。 
Tab:AddToggle("自动刷钱", false, function(state)
    print("当前状态: ", state)
end)
AddSlider (数值调节) 通过拖拽调节数值大小。 
Tab:AddSlider("步行速度", 16, 200, 16, function(v)
    game.Players.LocalPlayer.Character.Humanoid.WalkSpeed = v
end)
2. 核心技术说明

除了上述基础组件，zhiUI 还在底层实现了多项优化技术，确保脚本运行的稳定性与隐蔽性。

🛡️ 反截图与反检测

自动优先选用 gethui() 环境。这种方式能将 UI 隐藏在游戏的常规渲染层之外，有效绕过部分截图类反作弊检测。

📱 移动端自适应

内置 UIScale 监听器。当用户在手机端运行脚本时，UI 比例会自动缩放 75%，防止按钮太大导致无法操作游戏。

⚡ 物理果冻动画

所有交互均基于 TweenService 的 Elastic 与 Back 算法，提供极致的点击反馈感，不再是死板的弹出消失。

🧹 自动垃圾回收

启动时会自动清理残留的 zhiUI 实例。哪怕你的脚本崩溃了，下次运行也会自动重置环境，不会造成卡顿。

3. 常见问题 (FAQ)

Q: 为什么 UI 没有显示？

A: 请检查你的执行器（Executor）是否支持 game:HttpGet。如果是内部脚本，请确保 CoreGui 权限已开启。

Q: 如何修改全局颜色？

A: 源码顶部的 Theme 表中含有 Accent 变量。你可以将其修改为你喜欢的任意 Color3 数值，所有组件将自动同步颜色。

Q: 最小化球找不到了怎么办？

A: 最小化球默认出现在屏幕正上方。如果被遮挡，重新运行脚本即可，自动清理功能会重置它的位置。

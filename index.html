zhiUI Hub

为性能与审美而生的 Roblox 现代化 UI 框架

响应式缩放

内置移动端自适应逻辑。当检测到屏幕宽度小于 800px 时，UI 自动按 0.75x 比例缩小，确保在手机端不会遮挡游戏视野。

果冻动画反馈

基于物理算法的弹性动画（Elastic & Back）。无论是 Tab 切换还是按钮点击，都能提供极其丝滑的视觉反馈。

智能管理

支持一键最小化为“悬浮球”，支持自动清理旧版 UI 防止残留，支持通过 gethui() 实现反截图检测。

全功能组件清单

🔘 Button：具备物理挤压感的动作按钮。

☑️ Toggle：仿 iOS 滑动开关，带平滑变色。

📏 Slider：高精度数值滑动条，支持范围自定义。

📜 Dropdown：动态高度折叠列表，支持长选项。

⌨️ Input：美化的文本输入框，支持失去焦点回调。

🔔 Notify：右下角全局通知系统，支持标题与描述。

📝 Label：支持代码动态更新内容的文本标签。

➖ Divider：强调色风格的分层分割线。

📂 Tab：侧边栏分类系统，支持自动画布高度调整。

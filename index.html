zhiUI Function Wiki

文档包含全部 API 调用示例及一键复制功能

系统通知
Notify (全局弹窗)

在屏幕右下角显示即时消息提示。

zhiUI:Notify("系统", "脚本加载成功！", 5)
交互组件
AddButton (点击按钮)

创建一个带有物理回弹效果的可点击按钮。

Tab:AddButton("执行动作", function()
    print("已触发回调")
end)
AddToggle (开关切换)

用于开启/关闭特定逻辑，状态实时回传。

Tab:AddToggle("自动刷图", false, function(state)
    print("当前状态: ", state)
end)
AddSlider (数值滑动条)

精确控制数值大小（如速度、重力等）。

Tab:AddSlider("步行速度", 16, 100, 16, function(val)
    game.Players.LocalPlayer.Character.Humanoid.WalkSpeed = val
end)
AddDropdown (下拉菜单)

节省空间的列表选择器，点击展开/收起。

Tab:AddDropdown("选择传送点", {"大厅", "商店", "地牢"}, function(opt)
    print("目标已设为: " .. opt)
end)
装饰与文本
AddLabel & AddDivider

用于排版说明和视觉分割。

Tab:AddLabel("版本: v1.0.2 Stable")
Tab:AddDivider()

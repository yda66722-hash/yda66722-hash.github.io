zhiUI Framework

功能百科与调用示例

以下是 zhiUI 提供的所有组件及其对应的代码调用方式。

全局通知系统
GLOBAL Notify (弹窗通知)

在屏幕右下角弹出信息提示，适用于脚本启动、任务完成或报错提醒。

-- 参数：标题, 内容, 持续秒数
zhiUI:Notify("系统", "脚本加载成功！", 5)
基础交互组件
ELEMENT AddButton (按钮)

最常用的组件，带有果冻回弹点击动效，用于执行一次性动作。

Tab:AddButton("执行传送", function()
    print("玩家已传送")
end)
ELEMENT AddToggle (开关)

iOS 风格的滑动开关，用于控制开启或关闭循环功能（如自动挂机）。

Tab:AddToggle("自动刷金币", false, function(state)
    print("当前状态：", state) -- state 为布尔值
end)
ELEMENT AddSlider (滑动条)

调节数值的利器。支持自定义步长范围，并带有数值实时显示。

-- 标题, 最小值, 最大值, 默认值, 回调
Tab:AddSlider("步行速度", 16, 200, 16, function(v)
    game.Players.LocalPlayer.Character.Humanoid.WalkSpeed = v
end)
ELEMENT AddDropdown (下拉框)

节省空间的选项菜单，点击展开，选中后自动折叠并回传选项内容。

Tab:AddDropdown("选择模式", {"近战", "远程", "全能"}, function(val)
    print("已切换至：" .. val)
end)
ELEMENT AddInput (输入框)

允许用户手动输入文本，常用于输入特定的 ID、消息内容或密钥。

Tab:AddInput("目标玩家", "输入玩家ID...", function(text)
    print("已锁定玩家：" .. text)
end)
布局辅助
UI AddLabel & AddDivider

Label 用于显示提示文本（可动态更新），Divider 用于插入强调色分割线。

local myLabel = Tab:AddLabel("作者: zhi")
myLabel:Set("状态: 运行正常") -- 动态更新文本
Tab:AddDivider() -- 插入横线

zhiUI 全功能百科

本文档基于底层源码，涵盖所有 API 接口与交互逻辑。

📡 第一阶段：引用与创建

zhiUI:CreateWindow(config) 必选

启动框架的核心。它会自动执行：UI 清理、环境检测（gethui/CoreGui）、移动端自适应（UIScale）以及主窗口拖拽初始化。

local Window = zhiUI:CreateWindow({
    Title = "zhiUI Premium Hub" -- 你的标题
})

🔔 第二阶段：反馈系统

zhiUI:Notify(title, desc, duration)

在屏幕右下角呼出一个果冻动效弹窗。内容过长时会自动折叠文本（TextWrapped）。

zhiUI:Notify("系统公告", "脚本已成功加载，祝你游戏愉快！", 5)

📂 第三阶段：结构定义

Window:AddTab(name)

创建侧边栏分类。每个 Tab 按钮都带有 JellyTab 悬停缩放动画。点击时自动处理 CanvasSize 滑动区域。

local MainTab = Window:AddTab("主要功能")
local SetTab = Window:AddTab("设置选项")

🛠️ 第四阶段：全量组件 (All Elements)

Tab:AddButton(text, callback)

基础点击组件。内置 JellyClick 物理弹性反馈，手感极佳。

MainTab:AddButton("重置传送点", function()
    print("触发动作")
end)

Tab:AddToggle(text, default, callback)

逻辑开关。状态改变时，滑动圆点会执行 Elastic 动画，并根据状态切换强调色。

MainTab:AddToggle("自动攻击", false, function(state)
    _G.AutoAttack = state
end)

Tab:AddSlider(text, min, max, default, callback)

数值调节器。支持实时滑动更新数值，常用于步行速度或重力调节。

MainTab:AddSlider("移动速度", 16, 500, 16, function(v)
    game.Players.LocalPlayer.Character.Humanoid.WalkSpeed = v
end)

Tab:AddDropdown(text, list, callback)

折叠选择框。动态计算高度，点击选项后自动收回并更新主显示文本。

MainTab:AddDropdown("选择模式", {"高效率", "平衡", "低占用"}, function(val)
    print("当前模式：" .. val)
end)

Tab:AddInput(text, placeholder, callback)

文本输入。用户输入完成后（按下回车或点选别处）回传字符串。

MainTab:AddInput("特定目标", "输入玩家名称...", function(t)
    Target = t
end)

Tab:AddLabel(text) & :Set(newText)

文本标签。不仅能显示，还能返回一个对象用于后续动态修改文字。

local MyLabel = MainTab:AddLabel("当前金币: 0")
-- 之后可以用 MyLabel:Set("当前金币: 999") 动态刷新

Tab:AddDivider()

视觉分割线。在长页面中区分不同功能模块，自带强调色透明度处理。

MainTab:AddDivider()

📜 第五阶段：核心逻辑说明

1. UI 渲染安全：本库内置了自动前缀检测。如果你的脚本运行出错崩了，第二次运行会自动销毁之前的残余窗口，绝不占内存。

2. 最小化球逻辑：源码中的绿色/黄色控制按钮不仅是摆设。点击黄色按钮会触发 UI 缩放动画并隐藏至顶部的“悬浮球”，再次点击悬浮球即可恢复。

3. 主题自定义：在源码最上方的 Theme 表中，你可以修改 Accent 颜色。改一处，全库所有开关、进度条、分割线都会同步变色。

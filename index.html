全功能 API 参考手册

基于核心源码的完整组件调用指南

1. 引用与初始化
远程引用 (Loadstring) 通过 GitHub 链接直接在脚本中加载 UI 库。 
local zhiUI = loadstring(game:HttpGet("https://raw.githubusercontent.com/yda66722-hash/zhiUI/refs/heads/main/zhiUI"))()
CreateWindow (创建窗口) 初始化主窗体，包含自动清理旧 UI 和移动端适配功能。 
local Win = zhiUI:CreateWindow({
    Title = "我的脚本面板"
})
2. 功能组件 (Elements)
Notify (通知系统) 在屏幕右下角弹出果冻动画样式的消息提醒。 
-- 标题, 内容, 持续秒数
zhiUI:Notify("系统提示", "脚本运行成功", 5)
AddTab (添加分页) 在侧边栏创建一个分类页。后续组件需添加在此对象下。 
local Tab = Win:AddTab("战斗功能")
AddButton (基础按钮) 带有物理挤压效果（JellyClick）的基础交互组件。 
Tab:AddButton("传送至終点", function()
    print("正在传送...")
end)
AddToggle (开关) iOS 风格滑动开关，用于控制功能开启/关闭。 
Tab:AddToggle("自动挂机", false, function(state)
    print("状态: ", state)
end)
AddSlider (滑动条) 精确控制数值范围，如速度、高度或重力。 
Tab:AddSlider("步行速度", 16, 200, 16, function(v)
    game.Players.LocalPlayer.Character.Humanoid.WalkSpeed = v
end)
AddDropdown (下拉框) 折叠式选项菜单，支持动态展开与收起。 
Tab:AddDropdown("选择地图", {"森林", "沙漠", "雪山"}, function(val)
    print("已选择: " .. val)
end)
AddInput (文本输入框) 获取用户手动输入的文本，支持占位符提示。 
Tab:AddInput("玩家ID", "输入名称...", function(text)
    print("目标锁定: " .. text)
end)
3. 辅助组件
Label & Divider (文本与分割) 用于显示提示文字（可动态更新）及插入强调色分割线。 
local Info = Tab:AddLabel("初始化中...")
Info:Set("连接服务器成功") -- 动态更新
Tab:AddDivider() -- 分割线
